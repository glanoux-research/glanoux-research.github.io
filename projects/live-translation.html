Live Translation

Real-time Korean-to-English translation of lectures, running on my own GPU. A laptop streams the lecturer’s voice to a desktop, and English text comes back while the lecture goes on. Nothing leaves machines I control.

Why I built it

I am a French student at Seoul National University, and most of my courses are taught in Korean. Before writing any code, I tried the three obvious options:

  • Paid speech-to-text APIs. They work well, but sending hours of lectures every week gets expensive.
  • Free online translators. The quality on spoken lectures is poor, and the lecturer’s voice ends up on a third-party server.
  • Translation earbuds. They rely on the same online translator, so they have the same two problems.

So the goal was simple: open-source models, my own hardware, and audio that never leaves machines I control.

How it works

Client · laptop

Capture and stream

ffmpeg records the microphone through PulseAudio as raw 16 kHz mono floats. The client cuts it into 0.2-second chunks, sends them over a WebSocket and prints every update from the server. A bounded 5-second buffer keeps memory flat if the network stalls.

Server · GPU

Transcribe and translate

The server collects audio until it has about 3 seconds, then runs Whisper’s translate task with Korean as the source language. It sends the English text back only when it has changed, and keeps the last second of audio as context for the next window.

The core loop

The whole server fits in about forty lines. This is the part that does the work, slightly shortened:

async def handler(websocket):
    audio_buffer = np.array([], dtype=np.float32)
    last_sent_text = ""

    async for message in websocket:
        chunk = np.frombuffer(message, dtype=np.float32)
        audio_buffer = np.concatenate([audio_buffer, chunk])

        if len(audio_buffer) >= SAMPLE_RATE * BUFFER_SECONDS:  # ~3 s collected
            segments, _ = model.transcribe(audio_buffer, task="translate",
                                           language="ko", beam_size=5)
            full_text = " ".join(seg.text for seg in segments).strip()

            if full_text != last_sent_text:                   # send only changes
                await websocket.send(full_text)
                last_sent_text = full_text

            audio_buffer = audio_buffer[-SAMPLE_RATE:]           # keep 1 s of context

Running it

  1. On the GPU machine: pip install -r requirements.txt, then ./launch_server.sh. The first run downloads the large-v3 model. On a smaller GPU, switch to medium or small in server.py.
  2. On the laptop (Linux, PulseAudio, ffmpeg): find the microphone with pactl list short sources. Set DEVICE and SERVER_URI in client.py, then run python client.py.

Full instructions are in the README on GitHub.

Limits

  • English output only. Whisper’s translate task always produces English, and the source language is fixed to Korean.
  • Overlapping windows. The server re-transcribes overlapping 3-second windows, so a sentence cut at a window edge can appear twice or lose a word.
  • No security on the connection. The WebSocket is neither authenticated nor encrypted, so I only run it over a VPN.
  • Not measured yet. I have not yet measured latency or accuracy against other tools.
  • Recording lectures: ask the lecturer first, even for local, personal use.
